# World Forge

Процедурный генератор фэнтезийного мира. Проект развивается поэтапно: от поля высот и физической географии до климата, гидрологии, биомов, поселений, государств, экономики и истории.

Рабочая версия: **v0.7**

Сайт: https://world-forge.avdeevgreyfog.chatgpt.site/

Дата фиксации: **23 августа 2026 года**

## Текущий этап

Сейчас разрабатывается только первый фундаментальный слой — **карта высот**. Следующие модули интерфейса намеренно заблокированы. До утверждения геометрии поля нельзя добавлять реки, климат, биомы, города, государства и декоративные слои.

Основной визуальный референс — серия [Multiversal Maproom](https://www.youtube.com/@MultiversalMaproom), прежде всего [Fantasy Mapmaking | Part 1: Terrain Generation](https://www.youtube.com/watch?v=L3AqhxZq7C4). Проект использует референс как ориентир, но не ставит задачу копировать чужой продукт или неподтверждённый исходный код.

## Что реализовано в v0.7

- детерминированная генерация по `seed`;
- собственный двумерный градиентный шум;
- несколько октав fBm;
- quintic fade-функция `6t^5 - 15t^4 + 10t^3`;
- горизонтальное зацикливание поля;
- регулируемые базовая сетка, октавы, persistence, перераспределение и уровень моря;
- цветной и бинарный режимы отображения;
- просмотр координат и высоты точки;
- статистика и гистограмма высот;
- экспорт карты в PNG;
- отображение градиентных векторов.

## Визуализация высот

Вместо плавного градиента используется ступенчатая гипсометрическая карта без hillshade, теней, бликов и псевдоспутниковой текстуры.

### Вода — 6 уровней

От глубины к мелководью:

```text
#2c2e49
#424b82
#4f6ab8
#648fbe
#83b5ce
#a2dde1
```

### Суша — 10 уровней

От береговых низменностей к вершинам:

```text
#3a8e62
#43984b
#66a24e
#86aa54
#a2b159
#b9b05e
#c0a368
#d3af91
#e8cbc2
#f9f5f4
```

Вода и суша нормализуются отдельно по фактическому диапазону высот конкретной генерации. Это сохраняет все ступени палитры, но пока не выражает абсолютные метры.

## Текущие параметры по умолчанию

```text
Внутреннее поле: 512 x 320
Размер базовой сетки: 4
Количество октав: 6
Persistence: 0.52
Перераспределение высот: 1.05
Уровень моря: 0.50
```

Упрощённая формула:

```text
raw = 0.5 + fractalNoise * 0.5
height = clamp(raw) ^ redistribution
```

## Главная нерешённая проблема

Палитра и способ отображения высот уже близки к выбранному принципу, но само поле остаётся слишком похоже на обычный многослойный шум:

- много раздробленных участков и мелких островов;
- одинаковый масштаб шума по всей карте;
- нет выраженного континентального каркаса;
- высокие зоны возникают как случайные пятна;
- недостаточно заметна иерархия «материк → регион → локальная деталь».

Следующая работа должна менять геометрию поля, а не маскировать её текстурами или декоративными слоями.

## Рекомендуемое продолжение

1. Зафиксировать текущую палитру и временно её не менять.
2. Разделить генерацию на `continentalField`, `regionalField` и `detailField`.
3. Снизить влияние мелких октав.
4. Проверить мягкий domain warping для вытянутых и менее регулярных форм.
5. Контролировать долю суши, количество крупных связанных массивов и мелких островов.
6. Проверять алгоритм минимум на 10 seed, а не выбирать одну удачную карту.
7. Не переходить к следующим слоям мира, пока бинарная карта «суша / море» не станет убедительной сама по себе.

Начальная рабочая гипотеза, а не утверждённая формула:

```text
height = continentalField * 0.65
       + regionalField    * 0.25
       + detailField      * 0.10
```

## Критерии принятия первого этапа

- крупные связанные массивы суши;
- мелкие детали подчинены крупным;
- разнообразный, но не рассыпающийся берег;
- вложенные области высот;
- высокие зоны преимущественно внутри суши;
- глубокие зоны преимущественно вдали от берега;
- отсутствие заметного вертикального шва;
- большинство из 10 последовательных seed дают осмысленный результат;
- цветной и бинарный режимы одинаково хорошо показывают структуру.

## Важное уточнение по референсу

Полного покадрового просмотра всех видео Multiversal Maproom не было: в доступном облачном браузере видеопоток YouTube не воспроизводился, а автоматические субтитры были недоступны. Подтверждённые выводы основаны на доступных метаданных и на кадре из первого видео, предоставленном пользователем. Точные формулы автора неизвестны; любые технические реконструкции являются рабочими гипотезами.

## Запуск локально

Требуется Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
```

Проверка сборки:

```bash
npm run build
```

Основная реализация находится в:

- `app/page.tsx` — генератор, Canvas и интерфейс;
- `app/globals.css` — стили приложения.

## Инструкция для следующего чата

Продолжать нужно именно этот репозиторий и существующий сайт World Forge. Не создавать новый проект, не менять палитру без нового согласования и не добавлять следующие этапы генератора. Первая задача — улучшить крупномасштабную структуру поля высот, визуально проверить несколько seed и показать результат на существующем сайте.
