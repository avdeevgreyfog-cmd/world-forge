# v0.7.4 World Builder

Experimental branch: constrained world composition + Legacy detail.

Goals:
- Generate a full world, not a single unconstrained noise field.
- Prefer 3–5 major landmasses.
- Keep ocean visible on left/right map edges.
- Use Legacy-style noise for coastline and interior relief detail.
- Generate several candidates and automatically select the best-scoring world.
- Give users direct controls for land share, continent count and coastline complexity.
